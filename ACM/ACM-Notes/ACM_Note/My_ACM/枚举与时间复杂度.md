
# 概述
	计算机 1s 可以运行 1e8 次
	因此解枚举题的核心是：
	尽可能缩小枚举范围，避免TLE

# 例题

## 回文质数

[P2241 统计方形（数据加强版） - 洛谷](https://www.luogu.com.cn/problem/P2241)

### 思路

	缩小枚举的范围。
	
	首先： 5 ~ 1e8 中回文数的个数非常少，因此，枚举所有的回文数，再判断这些回文数是否为质数。
	
	其次： 回文质数的尾数不能是偶数。
	
	最后： 利用回文数的对称性，排除位数为偶数的数——它们可以被11整除。
	
	被11整除的数的特征：奇数位，偶数位之和的差可以被11整除。0自然可以被11整除。
	
	因此，算法的流程是： 
	
	一位，两位数特判
	
	三位以上的数，通过多重循环直接构造出回文数，再判定
	
	第一，是否在[a,b]区间内
	
	第二，是否位质数
	
	满足这些条件的输出即可。
### 代码
```cpp
// 素数检验工具
bool isprime(int n)
{
	if (n < 2) return false;
	for(int i = 2; i <= n / i; i ++) if (n % i == 0) return false;
	return true;
} 

// 压位，大于七位数的回文数必然不是质数
if (b > 9999999) b = 9999999;

// 先构造，再判断是否满足两个条件
	for(int d1 = 1; d1 <= 9; d1 += 2)
		for(int d2 = 0; d2 <= 9; d2 ++)
		{
			int num = 100* d1 + 10 * d2 + d1;
			if ((num >= a && num <= b) && isprime(num)) cout << num << "\n";
		}
```
